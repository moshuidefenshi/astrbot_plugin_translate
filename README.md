# 英文回复翻译

将 AstrBot 聊天模型的英文回复在发送前翻译成简体中文。模型的会话历史仍保留英文。插件仅处理聊天模型的文本回复，不处理命令回执、插件消息和图片等非文本组件。

## 安装与配置

将本仓库克隆到 AstrBot 的 `data/plugins/astrbot_plugin_translate`，在 WebUI 中加载插件。插件需要 AstrBot 4.9.2 或更新的 4.x 版本；依赖由 `requirements.txt` 声明。

插件配置默认使用 DeepL API。填写 API Key，并按套餐选择 `free` 或 `pro`。也可以将翻译方式改为 `astrbot_llm`，从 AstrBot 已配置的聊天模型中选择一个能输出简体中文的独立模型。翻译服务未配置或请求失败时，原英文回复会照常发送。

AstrBot 管理员在目标会话发送 `/翻译` 开启，发送 `/翻译 关闭` 关闭。各会话状态独立保存，默认关闭。这里的管理员指 AstrBot 中配置的管理员，不是群平台的群主或群管理员。
