# AstrBot 英文回复翻译插件

本项目为 **Vibe Coding产物**。

有些聊天模型只会用英文回答。这个插件会在 AstrBot 发出回复前，把模型回答中的英文翻译成简体中文。聊天模型仍然使用自己的英文原文继续对话。

## 安装

1. 在 AstrBot 的插件管理页面安装这个仓库：`https://github.com/moshuidefenshi/astrbot_plugin_translate`。也可以把仓库放进 AstrBot 的 `data/plugins/astrbot_plugin_translate` 目录，然后在插件管理页面加载。
2. 打开插件设置，选一种翻译方式，并填好对应的配置。

## 选择翻译方式

**用 DeepL 翻译：** 在插件设置中保持 `deepl`，填入 DeepL API Key。免费套餐选 `free`，付费套餐选 `pro`。这是默认的翻译方式。

**用另一个 AI 模型翻译：** 先在 AstrBot 中添加一个能输出中文的聊天模型，再把插件的翻译方式改成 `astrbot_llm`，并在“独立翻译模型”中选它。这里选的模型应与平时聊天的英文模型分开。

## 开关指令

翻译**默认开启**，每个群聊或私聊单独保存开关状态。只有 AstrBot 管理员能发送以下指令：

- `/翻译 开启`：开启当前会话的翻译。
- `/翻译 关闭`：关闭当前会话的翻译。

如果翻译服务尚未配置或请求失败，AstrBot 会照常发送原英文回复。插件只处理聊天模型的文字回复，不会翻译命令提示、其他插件消息、图片或代码块。
